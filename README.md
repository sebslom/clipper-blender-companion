## ✨ Overview

**Clipper Companion** is a vintage-inspired, interactive 3D Viewport assistant built natively for Blender. Clipper lives directly inside your 3D workspace, tracking your cursor, blinking, talking, and dynamically guiding you through step-by-step 3D modeling and animation workflows.

Whether you're starting with Blender basics or mastering advanced **Geometry Nodes**, **Inverse Kinematics**, and **AgX Color Science**, Clipper validates your viewport actions in real-time and provides instant feedback!

## 📥 Installation Guide

1. Download the latest release ZIP file (or clone this repository).
2. Launch **Blender** (version 3.0 or newer).
3. Navigate to **Edit** > **Preferences** > **Add-ons**.
4. Click the **Install...** button at the top right.
5. Select the downloaded `clippy-companion-main.zip` file and click **Install Add-on**.
6. Check the box next to **`Interface: Clipper Companion`** to enable it.
7. Open the 3D Viewport sidebar by pressing **`N`**, select the **`Clipper`** tab, and click **Summon Clipper**!

## 💡 65+ Pro Tips & Shortcuts

Clicking Clipper at any time will trigger one of **over 65 expert tips** covering viewport shortcuts, shading secrets, topology rules, and performance tricks in both **English** and **Polski**.

### ⌨️ Quick Shortcut Cheat Sheet
| Category | Shortcut | Action |
|---|---|---|
| **Navigation** | `NumPad 1 / 3 / 7` | Front / Right / Top Orthographic View |
| **Navigation** | `NumPad 0` | Toggle Active Camera View |
| **Navigation** | `Slash (/)` | Local View Isolation Toggle |
| **Modeling** | `Tab` | Switch between Object Mode and Edit Mode |
| **Modeling** | `G / R / S` | Move (Grab) / Rotate / Scale |
| **Modeling** | `Ctrl + R` | Add Loop Cut |
| **Modeling** | `Ctrl + B` | Bevel Edges or Vertices (`Ctrl+Shift+B`) |
| **Modeling** | `I / E` | Inset Faces / Extrude Faces |
| **Shading** | `Z` | Open Shading Pie Menu (Wireframe / Solid / Material / Rendered) |
| **Nodes** | `Ctrl + T` | (Node Wrangler) Add Mapping + Texture Coordinate Nodes |
| **General** | `F3` | Quick Operator Search Bar |
| **General** | `Alt + D` | Create Linked Duplicates (Saves RAM) |
